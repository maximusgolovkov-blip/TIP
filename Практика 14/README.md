# Практическое занятие №14 (C++)

Решения трёх задач из практического занятия.

## Файлы

- `task1_brackets.cpp` — **Задача №1**: проверка правильной скобочной последовательности.
- `task2_unique_words.cpp` — **Задача №2**: вывод уникальных слов текста (без учёта регистра и знаков препинания) в порядке первого появления.
- `task3_min_stack.cpp` — **Задача №3**: собственная реализация стека с операциями `push`, `pop`, `empty` и поиском минимума `getMin()` за `O(1)`.

## Сборка и запуск (Windows, g++/MinGW)

Откройте папку `Практика14` в VS Code и выполните в терминале:

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -pedantic task1_brackets.cpp -o task1.exe
g++ -std=c++17 -O2 -Wall -Wextra -pedantic task2_unique_words.cpp -o task2.exe
g++ -std=c++17 -O2 -Wall -Wextra -pedantic task3_min_stack.cpp -o task3.exe
```

Запуск:

```powershell
.\task1.exe
.\task2.exe
.\task3.exe
```

## Примеры

### Задача 1
Ввод:
```text
В МИРЭА и без меня?))
```
Вывод:
```text
no
```

### Задача 2
Ввод:
```text
Когда твоя лп начала тебя шипперить с дед инсайдом, ты что испытала – кринж или всё-таки рофл?
```
Вывод: каждое уникальное слово с новой строки в порядке первого появления (без учёта регистра и знаков препинания).

### Задача 3
Формат ввода для демонстрации:
```text
n
<команда 1>
...
<команда n>
```
Команды: `push x`, `pop`, `empty`, `top`, `min`.
